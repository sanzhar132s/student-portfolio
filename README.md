# Учебное портфолио Санжара

Откройте `index.html` двойным щелчком. Установка и сервер не нужны. В разделе «Избранные проекты» доступны три настоящих приложения:

- **Focus**: добавление, выполнение, фильтрация и удаление задач; сохранение в браузере.
- **Budget**: расходы в тенге, категории, средний расход, удаление и экспорт CSV; сохранение в браузере.
- **Report**: чтение CSV, проверка данных, сумма и группировка по категориям. Есть встроенный пример и файл `projects/report/sample.csv`.

## Проекты

1. В Focus добавьте две задачи, отметьте одну выполненной и переключите фильтр. Обновите страницу: записи должны сохраниться, если браузер разрешает localStorage.
2. В Budget добавьте две покупки в разных категориях. Проверьте сумму и скачайте CSV.
3. Загрузите этот CSV в Report. Число записей и общая сумма должны совпасть с Budget. Можно также нажать «Загрузить пример»: 4 записи, сумма 5000, среднее 1250.

Все приложения используют HTML, CSS и JavaScript без зависимостей. Данные остаются в браузере. В приватном режиме или при запрете хранилища сохранение может быть недоступно. При открытии через file:// поведение localStorage зависит от браузера; для постоянного использования подходит GitHub Pages. Очистка данных браузера удалит записи.
